# V1.7.3 → V1.8 Implementation Notes

## Rate-limit policy

Fastify applies a global, environment-configurable limit (`RATE_LIMIT_MAX`, one-minute window). Sensitive or expensive routes narrow that policy:

| Group | Policy |
|---|---|
| Login | `LOGIN_RATE_LIMIT_MAX` / `LOGIN_RATE_LIMIT_WINDOW` plus persisted account lockout |
| Public analytics ingestion | 30/minute |
| CSV exports | 10/minute, authenticated and capability-checked |
| Media/admin mutations | Global limit plus auth/CSRF/origin/capability enforcement |
| Public catalog/detail/search | Global long limit; no extra aggressive per-IP limit |
| Health/readiness | Exempt from application rate limiting to avoid false provider outages |
| Sitemap/static media | Global/static provider handling |

429 responses use the regular API envelope with code `RATE_LIMITED` and include retry metadata/header from `@fastify/rate-limit`. `TRUST_PROXY=true` is required behind Render so Fastify derives the client IP from the trusted proxy chain; do not enable it on an untrusted direct public server.

## V1.8 behaviour

- Working-hours status supports the existing deterministic `HH:mm-HH:mm` text format and `Asia/Jakarta`, including overnight ranges. Unparseable/free-text hours remain visible but status is reported as unavailable.
- Public freshness uses `catalogUpdatedAt`/`updatedAt`, not analytics timestamps.
- Directions URLs are generated only from normalized coordinates and open with `noopener noreferrer`.
- UMKM completeness uses ten equal-weight criteria and exposes missing items; the backend scopes managed lists by role/ownership.
- CSV exports are admin/global-view only, UTF-8 BOM, quoted, and spreadsheet-formula neutralized.
- `/dashboard/bantuan` provides capability-aware export actions and short operational guidance.

## Bundle decision

Route-level lazy loading already isolates public details, map, dashboard, analytics, forms, and help. Build output should be compared before introducing `manualChunks`; this change deliberately adds no chunk policy until a measurable benefit is proven.
