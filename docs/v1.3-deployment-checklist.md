# V1.3 Deployment Checklist

## Infrastructure and database

- [ ] Production URL valid
- [ ] PostgreSQL connection valid
- [ ] Official migration completed
- [ ] Public integrity assertion passed
- [ ] Phone constraints `convalidated=true`
- [ ] S3 configured
- [ ] No production filesystem storage
- [ ] `/api/health` responds

## Frontend and public catalog

- [ ] Frontend build succeeds
- [ ] Public deep links work
- [ ] Legacy links canonicalize
- [ ] Published products visible
- [ ] Draft/archived hidden
- [ ] WhatsApp CTA works
- [ ] Clipboard fallback works
- [ ] Popup fallback works
- [ ] Analytics failure does not block CTA

## Acceptance

- [ ] Desktop E2E passes
- [ ] Mobile E2E passes
- [ ] Native 200% zoom passes
- [ ] Three consecutive full isolated runs pass

## Required commands

```bash
npm run lint
npm run typecheck
npm run test
VITE_PUBLIC_SITE_URL=https://audit.example npm run build
npm run test:harness-safety
npm run test:migration:existing:isolated
npm run test:integration:isolated
npm run test:e2e:isolated
npm run test:e2e:zoom-native:isolated
npm run verify:full:isolated
```

`audit.example` is a build-validation value only, not a production URL or sitemap host.

## SEO launch prerequisite

A production sitemap is deferred because neither the static frontend build nor the current API has a validated production site URL plus a safe sitemap publication contract. Before launch, implement and verify a sitemap containing only published UMKMs/products with canonical slugs and the real validated production origin. Do not advertise a placeholder sitemap in `robots.txt`.
