**Goal:** Tambah endpoint `DELETE /admin/users/:id` yang hanya bisa diakses superadmin untuk menghapus permanen user manapun (dengan safeguard).

**Architecture:** Backend-only changes: tambah capability `users:delete`, tambah route DELETE di `admin.ts`, tambah method `deleteUser` di repository. Frontend: tambah tombol hapus di UserListPage + API client method. Superadmin tidak bisa hapus diri sendiri, tidak bisa hapus superadmin aktif terakhir.

**Tech Stack:** TypeScript (Fastify backend, React frontend), Drizzle ORM, PostgreSQL

### Task 3: Tambah DELETE endpoint di admin routes

**Objective:** Tambah `DELETE /admin/users/:id` dengan guard dan safeguard

**Files:**
- Modify: `backend/src/routes/admin.ts`

**Step 1: Tambah route**

Setelah endpoint revoke-sessions (baris 58), sebelum audit-logs (baris 59), tambahkan:

```typescript
app.delete<{ Params: { id: string } }>('/admin/users/:id', { preHandler: [guards.authenticate, guards.origin, guards.csrf, guards.requireCapability('users:delete')] }, async (request, reply) => {
  const id = uuid.safeParse(request.params.id);
  if (!id.success) return reply.code(400).send(error('Invalid UUID', 'VALIDATION_ERROR'));
  const target = await repository.findUserById(id.data);
  if (!target) return reply.code(404).send(error('User not found', 'NOT_FOUND'));
  if (id.data === request.auth!.user.id) return reply.code(403).send(error('Tidak dapat menghapus akun sendiri.', 'CANNOT_DELETE_SELF'));
  if (target.role === 'superadmin' && target.isActive && await repository.countActiveSuperadmins() <= 1) {
    return reply.code(409).send(error('Super Admin aktif terakhir tidak dapat dihapus.', 'LAST_SUPERADMIN'));
  }
  const deleted = await repository.transaction(async (tx) => {
    const result = await tx.deleteUser(id.data);
    await tx.addAudit({ actorUserId: request.auth!.user.id, action: 'user.deleted', entityType: 'user', entityId: id.data, metadata: { username: target.username, displayName: target.displayName, role: target.role }, ...requestInfo(request) });
    return result;
  });
  if (!deleted) return reply.code(404).send(error('User not found', 'NOT_FOUND'));
  return { data: { id: id.data, deleted: true } };
});
```

## Risks & Tradeoffs

- **Hard delete vs soft delete**: Ini adalah hard delete. User akan hilang permanen dari database. UMKM dan produk yang terkait akan tetap ada dengan `ownerUserId = NULL`. Pastikan ini yang diinginkan.
- **Last superadmin safeguard**: Sudah di-handle — tidak bisa hapus superadmin aktif terakhir.
- **Self-delete safeguard**: Sudah di-handle — tidak bisa hapus diri sendiri.
- **Cascade behavior**: Sessions auto-deleted via FK cascade. UMKM, produk, media assets, audit logs — semua set null.
